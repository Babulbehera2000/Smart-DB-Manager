An AI-powered database management application built with Python, Oracle SQL, and Ollama AI. Smart DB Manager helps users interact with databases through a simple graphical interface while providing AI-assisted guidance for database operations.

## 🚀 Features

* User Registration and Login System
* Secure Authentication
* Oracle Database Connectivity
* Create, Read, Update, and Delete (CRUD) Operations
* Database Table Management
* Search and Filter Records
* User Activity History
* Admin Dashboard
* AI Assistant powered by Ollama
* SQL Query Assistance
* User-Friendly Python GUI
* Real-Time Database Interaction

## 🤖 AI Assistant

Smart DB Manager integrates Ollama AI to help users:

* Understand SQL queries
* Learn database concepts
* Get explanations of database operations
* Receive guidance on table creation and data management
* Improve productivity while working with Oracle databases

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Smart-DB-Manager.git
cd Smart-DB-Manager
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Oracle Database

* Install Oracle XE 21c
* Create the required tables
* Update database connection credentials in the configuration file

### 6. Install and Run Ollama

Install Ollama and download the required model.

Example:

```bash
ollama pull llama3
```

### 7. Run the Application

```bash
python main.py
```
